# RentWheels

RentWheels is a premium vehicle rental platform.

## How to Run

1.  **Open Terminal** in VS Code.
2.  Navigate to the project directory:
    ```bash
    cd rent_wheels
    ```
3.  **Backend Setup**:
    Navigate to the server directory and install dependencies:
    ```bash
    cd server
    pip install -r requirements.txt
    ```
4.  **Start the Server**:
    Run the Flask application:
    ```bash
    python app.py
    ```
5.  **Access the App**:
    Open your browser to: http://127.0.0.1:3000

## Features
- **Renter**: Search and book vehicles.
- **Owner**: List vehicles for rent.
- **Admin**: Manage users and platform (Login: `admin@rentwheels.com` / `admin123`).
